# Career Evidence

Produce the factual authority for downstream application work.

1. Load the profile manifest, accepted baseline, append-only corrections, source manifest, claim graph, and current user-supplied evidence.
2. Inventory every substantive evidence unit separately: role, ownership, scope, metric, mechanism, outcome, relationship, credential, honor, research result, venture, teaching engagement, and contact fact.
3. Trace each unit to an immutable source excerpt or explicit user assertion. Record conflicts without weakening either version silently; current supported evidence is not erased merely because an older graph lacks it.
4. Build the provenance chain `accomplishment -> engagement -> parent organization -> capacity -> source` before drafting begins.
5. Mark material baseline evidence as protected when audience tailoring could otherwise shrink seniority, ownership, scale, technical depth, or business consequence.
6. Emit schema-valid `evidence-bundle.json`. Its `claims` carry protection and source links, `provenance_requirements` carry parent-child rules, and `conflicts` carry unresolved source discrepancies. The résumé stage owns `coverage-ledger.json`.

Completion requires every relevant baseline evidence unit to have a source, status, provenance location, and protection decision. This stage does not choose positioning, write prose, paginate, or approve release.
